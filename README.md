# Tickordo

**Tickordo** is an AI-powered ticket triage system designed to help support teams analyze, classify, prioritize, and route support tickets.

The project is being developed as a practical software engineering project using **Go**, **Next.js**, and **PostgreSQL**, with AI integration for automated ticket analysis.

## Overview

Support teams often receive a large number of tickets that need to be manually reviewed and categorized before they can be handled.

Tickordo aims to assist this process by analyzing incoming tickets and providing structured information such as:

* Ticket category
* Priority
* Sentiment
* Suggested support team
* Ticket summary
* Suggested action
* AI confidence

The goal is not to replace support agents, but to help them understand and process tickets more efficiently.
